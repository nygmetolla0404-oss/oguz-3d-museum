# Түркі мемлекетінің қалыптасу тарихын зерттеудегі жаңа археологиялық деректер

Интерактивті 3D виртуалды музей: Оғыз мемлекеті (IX–XI ғғ.), Сыр бойы қалалары және Маңғыстау қорымдары.

- **Жоба авторы:** Амин Көркем Абайқызы
- **Жетекшісі:** Тлекбаева Марина Жанибекқызы

## Ашу
- `start.command` файлын екі рет басыңыз (macOS) — сайт `http://localhost:8080` мекенжайында ашылады.
- Немесе `index.html` файлын браузерде ашыңыз (3D кітапхана мен интернет-фотолар үшін интернет қажет).

## Мазмұны
- Қазақстанның тірі 3D картасы: 12 нысан, өзендер, керуен жолдары, тұман
- 10 ортағасырлық қаланың 3D реконструкциясы («Қазіргі күйі» режимімен)
- Кенті-баба, Үштам, Қаңға-баба және Бейнеу (Гүндіз Алп) қорымдары — жоба фотолары бойынша
- Жәдігерлер залы (10 экспонат)
- Қазақша дауыс (92 аудио), қобыз әуені, камера арқылы қолмен басқару

## Өзгерту
Мәтіндер: `src/content.json`, код: `src/js/`. Өзгерткеннен кейін:
```
pip install edge-tts
python3 src/build.py
```
